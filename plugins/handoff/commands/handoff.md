# /handoff — 다음 세션에 바통 넘기기

다음 세션의 Claude가 **이 파일 한 장만 읽고 같은 지점에서 이어가도록** 현재 컨텍스트를 압축해 저장.
(`/rewind`는 같은 세션을 과거로 되감기, `/handoff`는 `/clear` 너머 미래 세션으로 — 방향 반대.)

## 절차

1. **저장 경로** (Bash): `slug=$(basename "$PWD")`, `ts=$(date +%Y%m%d-%H%M%S)`, 경로 = `${TMPDIR:-/tmp}/handoff/${slug}-${ts}.md` — 디렉터리 없으면 `mkdir -p`.
2. 아래 포맷대로 본문 작성 → **Write**로 저장.
3. 인자가 있으면 그 주제로 §3 다음 액션·§5 첫 프롬프트를 편향.
4. 사용자에게 **저장 경로 + 다음 세션 첫 프롬프트** 만 반환.

## 포맷

```markdown
# Handoff — {{slug}} · {{YYYY-MM-DD HH:MM}}

> 다음 세션: 이 파일을 읽었으면 §3의 1번을 사용자에게 확인받고 진행. "어디까지 했지?" 묻지 말 것.

## 1. 요약 / 상태
- 한 줄: {{이 세션이 향한 목표}}
- cwd `{{경로}}` · git `{{branch}}@{{sha}}` ({{clean/dirty}})

## 2. 한 것 + 결정 (이유 한 줄씩)
- {{산출물·결정 — 왜 그렇게 정했는지. 사고 과정 X, 결과만}}

## 3. 다음 액션 (실행 단위, 우선순위 순)
1. {{구체 동사로 — 무엇을, 어디서, 결과물}}

## 4. 미해결 / 보류
- {{결론 못 낸 것}} (없으면 "없음")

## 5. 이어가기
- 읽을 파일: `{{경로}}` — {{왜}}
- 추천 스킬: {{다음 세션이 호출할 스킬}}
- 첫 프롬프트: "{{사용자가 그대로 붙여넣을 한 문장}}"
```

## 규칙

- **사실만, 날조 금지** — 모르면 "없음". 미래는 §3 액션으로.
- **압축이 목적** — 대화 전체 옮기지 말 것. 외부 산출물(PRD·계획·ADR·이슈·커밋·diff)은 복사 말고 경로/URL로 참조.
- **민감정보 레닥션** — API 키·비밀번호·PII는 절대 기록 금지.
- 한국어로. 보통 1.5~3K 토큰이면 충분.

## 최종 응답 (딱 이 형식)

```
저장됨: {{경로}}

/clear 후 다음 세션 첫 메시지:
> 이 handoff 읽고 이어서 작업해줘: {{경로}}
```

장황한 후기·확인 질문("더 추가할 것?") 금지. `open`으로 자동 열기 금지.
